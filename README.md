The funniest one-line farewell a phone says as its battery hits 1 percent, for make.fun's "Famous Last Words at 1 Percent" bounty.

> I've been at 1% for 45 minutes. I was bluffing. I can't bluff anymore.

(70 characters — one line, under the 199-character limit.)

## Run it

```sh
python3 main.py
```

It prints the line and writes it to `/output/entry.txt` for the make.fun grader. Pure Python standard library, no third-party packages.
